## Agent skills

### Issue tracker

Issues and specs live in this repo's GitHub Issues (`vilemaxim/scoretopia`), via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels, each named for its role: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` at the repo root (created lazily) and ADRs in `docs/adr/`. See `docs/agents/domain.md`.
